Project Description

A personal portfolio website developed to showcase my profile, educational background, technical and soft skills, and projects. The website provides an organized and user-friendly interface to present my academic journey and professional interests as an Artificial Intelligence student.

Technologies Used

- HTML5 – For structuring the web pages and organizing content.
- CSS3 – For styling, layout design, animations, and responsive design.
- JavaScript – For interactive features, dark mode functionality, and user interactions.

Features Implemented

- Personal Profile: Displays personal information, profile picture, and a short introduction.
- About Me Section: Presents a brief personal and academic overview.
- Skills Page: Showcases technical skills, soft skills, and language proficiency.
- Education and Experience: Displays academic background and internship experience with relevant logos.
- Projects Page: Provides a dedicated section to showcase projects.
- Contact Section: Includes email and LinkedIn links for easy communication.
- Dark Mode: Allows users to switch between light and dark themes, with the selected theme saved using Local Storage.
- Responsive Design: Adapts the layout to different screen sizes, including desktop and mobile devices.
- Interactive Navigation: Provides links between the different portfolio pages, with visual click effects.
